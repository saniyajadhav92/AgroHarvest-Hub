
AGROHARVEST HUB
===============
**Smart Farming & Agriculture Products Platform**

A Smart Web-Based Platform for Farmers

---

Project Overview
----------------

AgroHarvest Hub is a web-based agricultural platform developed to support farmers by providing easy access to agricultural products and smart farming-related services.

The platform aims to make agricultural shopping and farming information more accessible through a user-friendly website. Farmers can explore different agricultural products, manage their shopping activities, and access smart farming features.

This project combines agriculture and technology to provide a convenient digital platform for farmers.

The website is designed to help farmers explore agricultural products, place orders online, receive farming-related suggestions, and access useful features from one platform.

---

Project Objectives
------------------

- To provide farmers with an online platform for agricultural products.
- To make agricultural product searching and shopping easier.
- To provide crop recommendation support.
- To help users identify plant diseases through disease detection features.
- To provide an AI-based assistant for farming-related queries.
- To provide a simple and user-friendly shopping experience.
- To support multiple languages for better accessibility.
- To connect agriculture with modern web technologies.

Main Features
-------------

1. **Home Page**
   - Provides an introduction to AgroHarvest Hub.
   - Displays platform information and available services.
   - Provides navigation to different website sections.

2. **Agricultural Products**
   - Allows users to explore agricultural products.
   - Displays product details, descriptions, images, and prices.
   - Helps farmers find products online.

3. **Product Categories**
   Products are organized into different categories:
   - Seeds
   - Fertilizers
   - Agricultural Tools
   - Irrigation Products

4. **Product Search**
   - Helps users search for agricultural products.
   - Makes product discovery easier.

5. **Shopping Cart**
   - Allows users to add products to their cart.
   - Supports quantity management.
   - Displays selected products and total amount.

6. **Wishlist**
   - Allows users to save their favorite products.
   - Helps users access saved products later.

7. **User Authentication**
   - User Registration
   - User Login
   - User Logout
   - Account-based access

8. **Crop Recommendation**
   - Provides crop suggestions based on farming-related information.
   - Helps users explore suitable crop options.

9. **Plant Disease Detection**
   - Includes a plant disease detection feature.
   - Helps users identify possible plant diseases.

10. **AI Assistant**
    - Provides an AI-based assistant for farming-related questions.
    - Designed to support English, Marathi, and Hindi queries.

11. **Customer Reviews**
    - Allows users to submit product reviews and feedback.
    - Helps users share their experiences.

12. **Order Management**
    - Supports online order placement.
    - Allows users to view their orders.
    - Includes order cancellation functionality.

13. **Checkout System**
    - Collects customer and delivery information.
    - Supports Cash on Delivery and online payment options.

14. **Multilingual Support**
    - English
    - Marathi
    - Hindi

15. **Contact Page**
    - Provides contact information.
    - Allows users to submit messages through the contact form.

16. **User Dashboard**
    - Provides access to user-related information and website activities.

Installation and Setup
----------------------

Follow these steps to run the project on your local computer.

**Step 1: Clone the Repository**

```bash
git clone https://github.com/saniyajadhav92/AgroHarvest-Hub.git
```

**Step 2: Open the Project Folder**

```bash
cd AgroHarvest-Hub
```

**Step 3: Create a Virtual Environment**

```bash
python -m venv venv
```

**Step 4: Activate the Virtual Environment**

For Windows:

```bash
venv\Scripts\activate
```

**Step 5: Install Required Packages**

```bash
pip install -r requirements.txt
```

**Step 6: Apply Database Migrations**

```bash
python manage.py migrate
```

**Step 7: Start the Development Server**

```bash
python manage.py runserver
```

**Step 8: Open the Website**

Open your browser and visit:

http://127.0.0.1:8000/
